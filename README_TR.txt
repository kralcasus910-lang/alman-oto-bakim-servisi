ALMAN OTO BAKIM SERVİSİ — ANDROID PROJE DOSYALARI

Bu ZIP, uygulamanın Android Studio'da APK olarak derlenebilmesi için hazırlanmış proje başlangıç paketidir. Hazır APK değildir.

APK oluşturmak için:
1. ZIP dosyasını bir bilgisayara indirin ve çıkartın.
2. Android Studio'yu açın.
3. File > Open ile AlmanOtoAndroid klasörünü seçin.
4. Gradle senkronizasyonunun ve gerekli Android SDK bileşenlerinin kurulmasının bitmesini bekleyin.
5. Build > Build Bundle(s) / APK(s) > Build APK(s) seçin.
6. Derleme başarılı olursa APK bağlantısı Android Studio'da gösterilir.

Önemli:
- Bu proje çevrimdışı, yerel WebView tabanlı bir ilk sürüm kabuğudur.
- Kayıtlar uygulamanın yerel tarayıcı depolamasında tutulur; uygulama verilerini silmek kayıtları silebilir. Uygulamadaki yedekleme özelliğini kullanın.
- PDF/print ve fotoğraf seçimi Android sürümü ve WebView'e göre test edilmelidir.
- Bu paket gerçek cihazda derlenip test edilmiş değildir. APK yayımlamadan önce test edin.
